# プロフィール・人物分析生成プロンプト

以下をコピーして、他の人物やご自身のプロフィールを作成・分析する際にお使いください。

---

```markdown
# 指示
以下の【対象人物の情報】および【参考URL/テキスト】をもとに、人物分析を行い、その人物の強みや独自性が伝わる魅力的な「プロフィール情報」を作成してください。
必要に応じてWeb検索等を行い、バックボーンや活動実績を補完して整理してください。

---

## 出力フォーマット・構成

### 1. コアコンセプト
- 肩書・タグライン（一言で表す専門性）
- 活動理念・ミッション（大切にしている価値観やメッセージ）
- キーフレーズ・合言葉（あれば）

### 2. 人物像・バックボーン
- 氏名（愛称/読み）
- 拠点・活動エリア
- 保有資格・所属・専門領域
- 人生ストーリー・原体験（どのような葛藤や経験を経て現在の活動に至ったか）

### 3. 際立つ強み・独自性（USP: Unique Selling Proposition）
- 他者と何が違うのか（例: 異なる分野のかけ算、独自のメソッド、強み）を2〜3点に言語化して解説

### 4. 主な活動・提供サービス
- 現在展開している具体的なサービス、講座、プログラム等の概要

### 5. 用途別プロフィール文案
- **パターンA: 標準プロフィール（Webサイト・ブログ・登壇用 / 約300〜400文字）**
  - 経歴、想い、実績、提供価値がバランスよく伝わる構成
- **パターンB: ショートプロフィール（SNS・名刺・イベント紹介用 / 約100〜150文字）**
  - 要点を端的にまとめた簡潔な構成
- **パターンC: キャッチコピー・タグライン案（3〜5案）**
  - 魅力を一瞬で伝えるワンフレーズ

---

## 入力情報

### 【対象人物の情報】
- 名前（またはニックネーム）: [例: 菊池 伸哉（きくりん）]
- 主なキーワード・専門分野: [例: キャリアコンサルタント、そば打ち、コーチング]

### 【参考URL / 提供テキスト】
- HP / LP: [URL]
- note / ブログ: [URL]
- SNS (Instagram / X / Facebook等): [URL]
- （自由記述のメモや箇条書きなどがあれば記載）
```
